# English Scratch tutorial

The 13 sections in `meta.yml` are the standard project-site version of Lazy Tofu, with Scratch code examples and task panels.

- `step_1.md`: introduction, completed-game embed and sprite submission credit.
- `step_2.md`: Scratch starter link, remix/save instructions and starter embed.
- `step_3.md` to `step_12.md`: build the river game, full opening, sound and speed controls.
- `step_13.md`: optional customisation.
- `images/banner.png`: the existing game image reused from the editor repository.
- `code/lazy-tofu-starter/` and `code/lazy-tofu-complete/`: preserved source archives with both project YAML files set to `build: true`.
- `resources/lazy-tofu-starter.sb3`: offline starter.
- `solutions/lazy-tofu-complete.sb3`: completed offline solution.

The live guide uses [the Scratch starter](https://scratch.mit.edu/projects/1438003425/editor/) and [completed game](https://scratch.mit.edu/projects/1438005262/). It has no editor landing page and does not assume an editor is open alongside the instructions.

See [the authoring notes](../.github/authoring/README.md) for the source comparison and verification scope.
